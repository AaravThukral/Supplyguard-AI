# Problem Statement

Procurement teams evaluate suppliers across multiple criteria including quality, delivery reliability, financial strength, compliance, logistics, and disruption history. A simple single-criterion ranking can hide combinations of weaknesses.

SupplyGuard AI demonstrates a machine-learning workflow that classifies suppliers into three risk categories and presents the associated evidence in a form suitable for academic demonstration. The project is not a production approval engine: users must review source data, policies, and context before making decisions.

The current benchmark is synthetic. The core research questions are whether a leakage-controlled pipeline can learn the project-defined labels consistently, how interpretable model families compare, and how a prediction can be connected to transparent review guidance without overstating causal certainty.
